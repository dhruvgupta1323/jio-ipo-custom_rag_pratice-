Security Architecture & Guardrails

Multi-tier defense protecting against adversarial inputs, prompt extraction, and hallucinations

🛡️

1. Input Guardrails

  • Length Restrictions: Enforces maximum 2,000 character queries.
  • Injection Pattern Detection: Identifies and rejects prompts attempting instruction overrides (ignore prior instructions, reveal system prompt, etc.).
  • Sanitization: Strips control characters and binary payloads before embedding.
🔍

2. Retrieval Isolation

  • Strict Cosine Thresholding: Filters out non-relevant passages below 0.05 similarity.
  • Context Fencing: Excerpts are wrapped in XML-style <context> fences and treated purely as passive data, never instructions.
  • Financial Entity Boosting: Calibrated bonus for numerical IPO tokens (e.g., ₹30213, ₹1065, RJIL, PAT).
✅

3. Output Grounding & Citations

  • Mandatory [Page N] Verification: Parses all page citations in the generated answer.
  • Hallucination Defense: Flags answers that cite pages not present in retrieved source passages.
  • Disclaimer Compliance: Enforces Capstocks Equity Research educational notice.
